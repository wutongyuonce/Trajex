# 本地 Markdown 文件链接

## 目标

历史记录中的本机绝对路径 Markdown 链接不再让 Electron 导航离开 Trajex。存在的文本文件可在悬浮时预览开头；点击后由用户确认，再交给操作系统的默认应用打开。

## 范围

- 支持 POSIX 绝对路径和 `file://` URL。
- 支持 Codex 形式的 `/absolute/path/file.ts:42` 与 `:42:7` 行列后缀；后缀不属于实际文件路径。
- 仅预览常规文本文件的前 12 KiB；截断时标示已截断。
- 点击存在的文件时显示原生确认对话框；确认后以 Electron `shell.openPath()` 打开。

不在本次范围：相对链接、HTTP(S) 链接、目录预览、图片/二进制预览，以及让编辑器跳转到指定行。

## 交互

| 触发 | 文件存在且可预览 | 文件不存在、不可读或非文本 |
| --- | --- | --- |
| 悬浮 300 ms | 在窗口右下角显示文件路径与文本开头 | 不显示任何内容 |
| 点击 | 原生确认“是否用默认应用打开”；确认后打开 | 阻止默认导航，不显示弹窗 |

鼠标离开链接 120 ms 后关闭预览；进入下一条链接会取消关闭，因此连续查看时卡片保持原位。相同链接的结果在当前页面生命周期内缓存，避免反复读盘。

## 设计与安全边界

1. Renderer 只保留事件委托与浮层；不直接读取文件。
2. Preload 只暴露 `previewLocalMarkdownLink(href)` 与 `openLocalMarkdownLink(href)`。
3. Main process 对每一次请求重新解析、`stat` 和校验文件类型；打开操作不信任先前的预览结果。
4. 解析器只接受本机绝对路径与 `file:` URL，拒绝其他 scheme、相对路径和目录。读取上限为 12 KiB。
5. 窗口阻止 Markdown 触发的导航和新窗口，保证不存在、取消或异常时都停留在 Trajex。

该功能按“同一桌面用户主动浏览自身历史”设计；它不会把文件内容传出应用，也不会提供通用的 renderer 文件系统权限。

## 验收

- 点击有效 `/tmp/example.md:12` 不再导航，确认后由默认应用打开。
- 取消确认不打开文件。
- 悬浮有效文本链接后出现最多 12 KiB 的预览；移出后关闭。
- 不存在的链接没有预览也没有点击反馈。
- `http(s)`、相对链接保持原有行为。
- 路径解析有可独立运行的 Node 测试，覆盖 `file://`、URL 编码、行列后缀和拒绝非本机链接。
