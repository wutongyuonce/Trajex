# 会话右侧分段导航

Hover-driven Interactive Minimap Page Navigation 悬停驱动的交互式迷你地图页面导航

其中关键术语是：

* Minimap Page Navigation：页面内容的缩略导航
* Proximity-based Interaction：基于距离的交互反馈
* Fisheye Effect：靠近指针的项目局部放大
* Hover Reveal：悬停后显示波峰、高亮和章节标签
* Stable Scroll State：滚动不改变导航的默认视觉状态

## 目标

在 Session 详情页以固定在右侧的短横线导航，替代浏览器原生滚动条和底部消息分页器。短横线提供当前阅读位置，以及按对话轮次跳转的入口，视觉接近 Codex 的会话导航。

## 范围

- 仅改 `SessionDetail`；列表、Memory 和 Subagent 页面维持原有滚动条。
- 保留鼠标滚轮、触控板、键盘以及现有虚拟列表滚动行为。
- 保留详情页底部的四按钮分页器：外侧为上一/下一 session，内侧为上一/下一时间线项；session 切换按当前筛选和排序；右侧短线负责按对话轮次跳转。

不在本次范围：拖拽短横线、存储导航位置、跨页面复用组件。

## 概念与数据

一轮对话以一条用户消息为起点，跳转目标为该用户消息对应的时间线项。没有用户消息的历史记录退化为按可导航时间线项分段，确保任何会话都可导航。

`rounds` 为可跳转目标列表；每项包含时间线索引、用户消息和紧随其后的第一条助手消息。它直接从已加载的消息与现有 `timelineItems` 派生，不读取 DOM，不影响虚拟列表测量。没有匹配的助手消息时预览仍显示用户内容。

## 分段规则

1. 导航条以详情视口垂直中心为基准。视觉短线的中心间距固定为 16 px。
2. 少量轮次时，导航条高度随短线数增长；不从顶部或底部铺满。
3. 导航条最大高度为可视区域的约 2/3；容量为 `floor(视口高度 × 2/3 ÷ 16)`，至少一条。
4. 当 `rounds.length <= 容量`，一条短横线对应一轮。
5. 超出容量时，连续轮次按顺序均匀分入容量个桶；一条短横线代表一个连续轮次区间。
6. 点击短横线跳转到该桶的第一轮。阅读中的当前桶由视口起点的时间线索引映射决定，保证 `scrollToIndex(..., { align: 'start' })` 后仍是被点击的桶，而不是其后的桶。
7. 每条线的原生悬浮提示和 `aria-label` 显示“跳转至第 X 轮”或“跳转至第 X–Y 轮”。

分桶按以下确定性规则计算，和轮次内容高度、助手回复长度无关：设轮次数为 `N`、容量为 `C`，实际短线数为 `min(N, max(1, floor(C)))`。每桶基础轮次数为 `floor(N / 短线数)`，余数 `N % 短线数` 依次分配给最前面的桶。因此每桶只会比其他桶多一轮；桶始终覆盖原始轮次序列中连续、无重叠的范围。每个桶保存首轮和末轮的时间线索引：首轮索引用于点击跳转，末轮索引用于判断当前阅读位置。

例如：112 轮、可用容量 40 时，前 32 个桶各代表 3 轮，后 8 个桶各代表 2 轮；所有轮次恰好覆盖一次，没有重叠或遗漏。

例如：5 轮、容量 2 时，短线 1 覆盖第 1–3 轮并跳至第 1 轮，短线 2 覆盖第 4–5 轮并跳至第 4 轮。

## 交互与视觉

- 导航条固定在详情页右侧并垂直居中；短线始终等距，整体高度从一条逐步增长至约 2/3 视口。
- 常态短线使用低对比度 `--muted-2`；当前桶使用 `--fg` 并加宽。当前桶相邻两档短线按距离逐级变宽、变亮。
- 悬浮或键盘聚焦优先于当前阅读桶：指针所在短线立即成为最长、最亮的波峰，邻线按距离形成波形；移出或失焦后平滑回到当前阅读桶。
- 滚动或点击切换当前桶时，宽度、亮度和水平位移以短 CSS transition 连续过渡，形成随上下滚动传播的波动；不使用逐帧 JavaScript 动画。
- 悬浮或键盘聚焦短线时，在其左侧显示预览卡：上部为 `YOU` 和用户消息，下部为低对比度 `ASSISTANT` 和首条助手回复；两段各最多两行，超出省略。卡片不会遮挡短线，移出或失焦后关闭。
- 当一条短线覆盖多轮时，预览展示该桶第一轮的 `YOU / ASSISTANT`，不尝试拼接桶内多轮内容；这也与点击后落点一致。
- 短线是原生 `button`：可点击、可 Tab 聚焦、可用 Enter/Space 触发；焦点环使用主题 accent。
- Session 详情页隐藏原生滚动条，但滚动容器、滚轮和触控板行为不变。
- 小于两个可跳转目标时不显示导航条。

## 实现边界

- 在 `SessionDetail.vue` 中持有滚动容器的 `ResizeObserver`，将 2/3 视口高度转为容量。
- 纯分段计算放入一个轻量 `.mjs` 模块，并由 Node 的 `assert` 测试覆盖：逐轮、压缩分桶、完整覆盖、当前桶映射。
- 复用 `timelineViewport.scrollToIndex()` 完成跳转；不修改虚拟列表、滚动策略或数据加载逻辑。
- 不新增依赖。

## 验收

- 少量轮次时，导航条居中且高度随轮次增长，每条线可跳到对应用户轮次。
- 大量轮次时，导航条不超过视口约 2/3，短线间距不变；点击任意线会跳到它代表区间的第一轮。
- 悬浮短线立即成为最长短线；移出后当前阅读短线恢复为最长短线。
- 点击短线后，该短线与跳转的首轮保持一致并成为最长短线，不会偏移到下一根。
- 悬浮或 Tab 聚焦短线时，显示对应的 YOU / ASSISTANT 两段预览卡。
- 滚动、键盘导航、实时追加、恢复阅读位置后，当前短线正确更新。
- 无用户消息的会话仍可分段跳转。
- 详情页以外的页面滚动条不受影响。
